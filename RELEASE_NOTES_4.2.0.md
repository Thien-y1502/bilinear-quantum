# Bilinear Quantum 4.2.0

Version 4.2.0 preserves the 34-task facade and documents the composable
simulator-first neural namespace `bilinear_quantum.nn`.

The public documentation intentionally describes the stable user interface;
implementation and provider details remain behind the package boundary.

This release is simulator evidence only. It does not claim hardware-QPU
validation, application-dataset SOTA, or quantum advantage.
